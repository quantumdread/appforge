## Notes from manual catalog to preserve

These are hand-written gotchas that the MCP cannot surface from `describe_control`. Any reconciled catalog must preserve them as a hand-augmentation layer.

- **AddressInput**: NOT supported in Teams
- **Attachments**: Used inside Edit Forms for SP attachment columns. MaxAttachmentSize in MB. No OnSelect.
- **Badge**: Appearance: Filled/Outline/Ghost/Inverted · ThemeColor: Brand/Danger/Important/Informative/Severe/Subtle/Success/Warning
- **BarcodeReader**: NOT supported on desktop browsers - requires Power Apps mobile app · NOT supported in Teams Mobile
- **Button**: Icon uses string format e.g. Icon="Airplane" · Appearance: Primary/Secondary/Outline/Subtle/Transparent
- **Camera**: iOS: Only in mobile app not browser · NOT supported in Teams Mobile - use AddPicture instead
- **Classic/DatePicker**: Format: ShortDate/LongDate or custom like yyyy/mm/dd
- **Classic/Icon**: Use for clickable icons - Modern Icon has NO OnSelect
- **Classic/Radio**: Layout: Vertical/Horizontal
- **Classic/Slider**: Layout: Vertical/Horizontal
- **Classic/TextInput**: Mode: SingleLine/Multiline/Password · Format: text/number
- **Classic/Toggle**: TextPosition: left/right
- **ComboBox**: Modern ComboBox - for Classic use Classic/ComboBox
- **DatePicker**: Format: Short/LongAbbreviated/YearMonth/Custom
- **DropDown**: Modern DropDown - for Classic use Classic/DropDown
- **Form**: Layout:Vertical
- **FormViewer**: Layout:Vertical
- **Gallery**: Transition: Pop/Push/None · LoadingSpinner: None/Controls/Data
- **Icon**: Modern Icon - decorative only - NO OnSelect. Icon uses STRING values e.g. Icon="Money" not Icon.Currency. Use IconColor for color (NOT Color). For clickable icons use Classic/Icon
- **Image**: ImagePosition: Fill/Fit/Stretch/Tile/Center · External URLs must use HTTPS
- **InfoButton**: IconSize: small/medium/large
- **Label**: Live: Off/Polite/Assertive for screen readers
- **Map**: NOT supported in Teams
- **Microphone**: Teams: AAC format only (.MP4) · max 10 min duration · Teams blocks control during recording
- **Progress**: ProgressColor: brand/error/warning/success · Thickness: medium/large
- **Radio**: Modern Radio - Layout: vertical/horizontal/horizontalStacked
- **Slider**: Modern Slider - Layout: Vertical/Horizontal
- **Spinner**: Appearance: Primary/Inverted
- **Table**: ReflowBehavior: Reflow/GridOnly/ListOnly
- **Text**: Modern Text - use for labels. Weight: Bold/Semibold/Regular/Medium
- **TextInput**: Mode: use `='TextInputCanvas.Mode'.Multiline` (lowercase `l` in `line`) · Type: text/password/search · TriggerOutput: Delayed/FocusOut/Keypress

- **Toggle**: Modern Toggle - LabelPosition: before/after/above
