# Maintainer guides

These documents are for people maintaining AppForge's catalog, rules and analysis.

- [CONTEXT.md](CONTEXT.md) defines the project's domain and terminology.
- `design/` explains feature contracts and design decisions.
- `verification/` contains catalog verification procedures, recipes and operator tools.
- `verification-campaigns/` contains reviewed campaign inputs and reproduction cases.
- `acceptance/` contains persona acceptance fixtures and recorded observations.
- [VERIFICATION-CAMPAIGNS.md](VERIFICATION-CAMPAIGNS.md) explains campaign preparation,
  evidence review and local application.
- [SURVEY-AGGREGATE-EXPORT.md](SURVEY-AGGREGATE-EXPORT.md) explains aggregate exports.

Start with the [verification doctrine](../../knowledge/VERIFICATION-DOCTRINE.md)
and [contribution guide](../../CONTRIBUTING.md) before updating knowledge.
